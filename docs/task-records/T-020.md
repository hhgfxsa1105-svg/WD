| 结果与证据 | 类型检查 0 错误；Vitest 38 个文件 **958 项通过**（全量约 56 秒，其中回归集约 36 秒）；`npm audit` 0 漏洞；e2e **51/51**。覆盖：新手任务链每一步的数值逐项等于手算预期（如苏晚晴 20/30 → +3/+2 相识 → +3/+1 目睹突破 → +8/+6 任务反应 = 34/39）；没参与的 NPC 完全不变；解释的增量之和等于当前值；有未审计改动时自检确实报告不一致；4 个种子 × 400 步在内存、SQLite、重复运行三处结果相同；3 个种子的中途导出导入后续一致；导入写到一半数据库出错时玩家、世界、审计全部回滚。变异：见证记忆的关系变化绕过审计 → 2 条失败；导入不记差异事件 → 3 条失败；均已还原。另外，导出不带背包这一缺陷本身就是回归测试第一次运行发现的。 |

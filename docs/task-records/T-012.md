| 字段 | 内容 |

| 变更文件 | 新增 `packages/contracts/src/ai-plan.ts`（严格 schema）、`packages/game-rules/src/ai-plan.ts`（`extractJson`、`parseAiPlan`、`checkPlanTarget`、`EntityCatalog`）、`packages/game-rules/tests/ai-plan.test.ts`、`docs/ai-contract.md`；修改 `contracts/tests/contracts.test.ts`、两处 `index.ts`、`README.md`、`docs/open-settings.md` |
| 实现摘要 | **严格 schema**：`AiActionPlanSchema`，无任何数值字段；8 种动作类型；目标为 `{type, id}` 且 ID 限小写字母数字下划线；步骤、风险标签、文本长度均有上限。**宽容解析**：提取 JSON（围栏、多余的话、尾逗号、中文/单引号）、字段别名、动作同义词、未知字段/步骤/标签丢弃并记录、文本清洗与截断、缺 intent 用玩家原话；**永不抛异常**，通过者必满足严格 schema。**目标校验**：目标必须是已存在的实体，否则给出一句话澄清。设计决策：前置条件不由模型声明（取消 `requirements`），认不出的动作归为 `other` 并澄清而不是猜测，不需要目标的动作丢弃多余目标。 |
| 验证命令 | `npm run typecheck`；`npm test`；变异验证 ×2 |
| 结果与证据 | 类型检查 0 错误；game-rules 71 项（含 10000 次随机乱码/变异的模糊测试：不抛异常、通过者必合法；超深嵌套/巨量键/大数组各 < 500 ms；提示注入式输出不产生越权方案；原型污染键与重复键）；契约 schema 15 项非法样例全部被拒。变异：非法目标被静默忽略 → 8 条失败；交谈不转澄清 → 1 条失败；均已还原。 |

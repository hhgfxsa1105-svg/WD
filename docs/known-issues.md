# 已知问题与限制（S1 原型）

| 编号 | 描述 | 影响 | 处理阶段 |
|---|---|---|---|
| K-01 | 幂等键与行动记录仅在内存，服务重启后失效 | 重启前后用同一幂等键重试可能重复结算（浏览器每次点击都会生成新键，正常游玩不受影响） | T-010 |
| K-02 | 日志只在前端，刷新或重启后清空 | 失去历史叙事；状态本身不受影响 | T-010（审计事件）起 |
| K-03 | 行动数值为占位基线，晋级进度满 100 后没有突破逻辑 | 进度到顶后无后续 | T-007 / T-008 |
| K-04 | 货币兑换比例、魅力换算、功法评级经验系数尚未落地 | 仅有数据结构与展示 | S2 |
| K-05 | 设置/任务/消息/背包/功法/地图为占位面板 | 功能不可用 | S3–S5 |
| K-06 | 自由行动输入禁用 | 仅可使用固定行动 | S3 |
| K-07 | 无自动滚动备份与恢复演练，仅有手动导出/导入 | 存档文件损坏时只能依赖手动备份 | T-027 |
| K-08 | 界面字体依赖 Google Fonts，离线时回退系统字体 | 离线时观感略有差异 | 可选优化 |
| K-09 | 无组件级（jsdom）单元测试，前端行为由 Playwright 端到端覆盖 | 局部回归定位较慢 | S6 前评估 |
| K-10 | `better-sqlite3` 为原生模块，极少数平台需本地编译 | 安装可能需要构建工具 | 已在 README 说明 |
| K-11 | 仅在 Chromium 上做过端到端验证 | 其他浏览器未实测 | S6 |

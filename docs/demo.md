# 原型演示（S1）

从零开始，约 5 分钟走完原型循环。

## 1. 安装与启动
```bash
git clone <仓库地址> && cd WD
npm install
npm start          # 构建前端并启动本机服务
```
看到 `江湖志已启动：http://127.0.0.1:3000` 后，用浏览器打开该地址。首次启动会在 `data/jianghu.sqlite` 自动建库并写入初始角色。
开发调试用 `npm run dev`（前端 http://127.0.0.1:5173，热更新）。

## 2. 演示步骤
| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 打开首页 | 看到角色「林惊鸿」，境界「炼体」，六维、元宝/银两/铜钱、气血与体力条；炼体阶段没有内力条 |
| 2 | 点击名字 | 弹出头衔/称号/命格的评级与效果；再点名字、点空白处或按 Esc 收回 |
| 3 | 点底部「行动」→「修炼」 | 日志新增一条，标签显示「体力 −10」「经验 +11%」；体力 50 → 40，境界下的细进度线前进 |
| 4 | 连续修炼至体力耗尽（共 5 次） | 体力 0，进度 55%；「修炼」按钮禁用并提示「体力不足，先休息一下再修炼。」 |
| 5 | 点「休息」 | 体力 +15，修炼按钮恢复可用 |
| 6 | 刷新页面 | 体力与进度保持不变（以服务端存档为准） |
| 7 | 停止服务（Ctrl+C）后再 `npm start` | 状态仍然保留 |
| 8 | 缩窄浏览器到手机宽度 | 布局为单列，行动面板不遮挡底部导航 |
| 9 | 「行动」→「开始放置修炼」，稍等或关闭页面一段时间后再打开 | 打开页面自动结算离开期间的收益，日志出现「放置修炼 · 结算 N 分钟」；面板里也可「领取收益」「停止」 |
| 9.1 | 开始放置修炼后关闭页面或电脑，半天后回来重新打开 | 日志出现「离线 X，计入 Y（效率 50%）」；超过 12 小时则注明「已达上限」，只计入 12 小时 |
| 10 | 修炼进度到 100% 后点「突破」 | 弹窗显示成功率明细；可选一枚丹药（成败都消耗）；确认后日志记录成功率与掷点 |
| 11 | 突破失败后观察「突破」入口 | 进度回落、气血受损，入口显示冷却倒计时；24 小时后可再试 |
| 12 | 点「背包」 | 列出突破丹药及数量 |
| 13 | 点设置/任务/消息/功法/地图 | 显示「功能将在后续阶段开放」占位 |

自由行动输入框在 S3（AI 接入）前保持禁用。

## 3. 存档管理
```bash
npm run db:export -- my-save.json     # 导出
npm run db:import -- my-save.json     # 导入（先自动备份当前存档）
npm run db:migrate                    # 迁移到最新版本（启动时也会自动执行）
```

## 4. 自动化验证
```bash
npm run typecheck
npm test                              # 单元与集成测试
npm run test:e2e                      # 浏览器端到端 32 条（需先 npx playwright install chromium）
```
`test:e2e` 使用临时存档与随机端口，不影响你的真实存档。若本机已有 Chromium，可设置 `PW_CHROMIUM_PATH` 指向它。

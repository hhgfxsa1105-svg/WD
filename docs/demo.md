# 原型演示（S1）

从零开始，约 5 分钟走完原型循环。

## 1. 安装与启动
```bash
git clone <仓库地址> && cd WD
npm install
npm start          # 构建前端并启动本机服务
```
看到 `江湖志已启动：http://127.0.0.1:3000` 后，用浏览器打开该地址。首次启动会在 `data/jianghu.sqlite` 自动建库并写入初始角色。
开发调试用 `npm run dev`（前端 http://127.0.0.1:5173，热更新）。

## 2. 演示步骤
| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 打开首页 | 看到角色「林惊鸿」，境界「炼体」，六维、元宝/银两/铜钱、气血与体力条；炼体阶段没有内力条 |
| 2 | 点击名字 | 弹出头衔/称号/命格的评级与效果；再点名字、点空白处或按 Esc 收回 |
| 3 | 点底部「行动」→「修炼」 | 日志新增一条，标签显示「体力 −10」「经验 +11%」；体力 50 → 40，境界下的细进度线前进 |
| 4 | 连续修炼至体力耗尽（共 5 次） | 体力 0，进度 55%；「修炼」按钮禁用并提示「体力不足，先休息一下再修炼。」 |
| 5 | 点「休息」 | 体力 +15，修炼按钮恢复可用 |
| 6 | 刷新页面 | 体力、进度与**日志**都保持不变（日志由服务端保存，刷新、重启后仍在） |
| 7 | 停止服务（Ctrl+C）后再 `npm start` | 状态仍然保留 |
| 8 | 缩窄浏览器到手机宽度 | 布局为单列，行动面板不遮挡底部导航 |
| 9 | 「行动」→「开始放置修炼」，稍等或关闭页面一段时间后再打开 | 打开页面自动结算离开期间的收益，日志出现「放置修炼 · 结算 N 分钟」；面板里也可「领取收益」「停止」 |
| 9.1 | 开始放置修炼后关闭页面或电脑，半天后回来重新打开 | 日志出现「离线 X，计入 Y（效率 50%）」；超过 12 小时则注明「已达上限」，只计入 12 小时 |
| 10 | 修炼进度到 100% 后点「突破」 | 弹窗显示成功率明细；可选一枚丹药（成败都消耗）；确认后日志记录成功率与掷点 |
| 11 | 突破失败后观察「突破」入口 | 进度回落、气血受损，入口显示冷却倒计时；24 小时后可再试 |
| 12 | 点「背包」 | 列出突破丹药及数量 |
| 13 | 点设置/任务/消息/功法/地图 | 显示「功能将在后续阶段开放」占位 |

### 自由行动（需要 AI；没有密钥时用 `AI_PROVIDER=mock` 体验）
```bash
AI_PROVIDER=mock npm start      # 关键词规则的模拟模型，不需要密钥、不产生费用
```
| 步骤 | 预期 |
|---|---|
| 「行动」面板最上方输入「打坐一会儿」，点「行动」 | 面板显示「AI 理解为 修炼（已执行）」；日志新增一条，体力 −10；输入框清空 |
| 点快捷短句「服丹冲击下一境界」 | 只填入输入框，不会直接发送 |
| 输入「今天天气真好」 | 回复框写明「没有执行任何行动」，日志不变，输入内容保留 |
| 日志右上角 | 状态点：绿「AI 正常」；未配置显示灰「AI 未开启」；次数用完显示「AI 次数用完」 |
| AI 出故障（如密钥错误）时发送 | 回复框提示「AI 暂时无法响应，请稍后再试，或使用固定选项」，状态点变黄，输入保留；固定行动照常可用 |
| 突破成功后叙事生成失败 | 日志条目带「叙事待补」与「重新叙事」；点击重试，成功后文字被替换、标记消失，结果不变 |


### 地图、人物与任务（不需要 AI）
| 步骤 | 预期 |
|---|---|
| 点底部「地图」 | 看到「能去的地方」（只列相邻地点，写明体力消耗）与「这里的人」；体力不足时「前往」置灰并说明 |
| 点左侧「任务」图标 | 任务卡：「初入山门」可接取，「证明自己」未解锁；有可接取或可领取的任务时图标上有红点 |
| 接取「初入山门」，在地图里点「赵铁牛」→「打招呼」 | 人物卡显示态度（好感 +13、信任 22）、他记得「你与赵铁牛初次相识。」，展开「关系是怎么来的」可见「初次相识 好感 +3 · 信任 +2 · 已核对 ✓」；日志里立即出现「与守门弟子赵铁牛相识 ✓」 |
| 地图 →「前往青云山 · 练功场」→ 苏晚晴 → 打招呼 | 位置条变为练功场，日志出现「前往练功场 ✓」「可以领取奖励」「新任务「证明自己」可以接取了」 |
| 任务 →「领取奖励」 | 日志出现「铜钱 +100」与赵铁牛的反应；按钮变为「已领取」，不能再领 |
| （有 AI 时）在「行动」里输入「去练功场」 | 走与点地图相同的移动；说「去大殿」会被拒绝并说明不相邻 |

## 3. 存档管理
```bash
npm run db:export -- my-save.json     # 导出
npm run db:import -- my-save.json     # 导入（先自动备份当前存档）
npm run db:migrate                    # 迁移到最新版本（启动时也会自动执行）
```

## 4. 自动化验证
```bash
npm run typecheck
npm test                              # 单元与集成测试
npm run test:e2e                      # 浏览器端到端 38 条（需先 npx playwright install chromium）
npm run bench                         # 性能基线（见 docs/perf-baseline.md）
```
`test:e2e` 使用临时存档与随机端口，不影响你的真实存档。若本机已有 Chromium，可设置 `PW_CHROMIUM_PATH` 指向它。

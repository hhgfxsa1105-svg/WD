# 单机自用调整说明（相对 V1.0 文档基线）

项目确定为**完全单机、自己游玩、无公开上线计划**。以下调整优先于 V1.0 文档中的对应描述。

| 项目 | V1.0 | 调整后 |
|---|---|---|
| 数据库 | PostgreSQL | SQLite 本地文件（Drizzle） |
| 部署 | 静态托管 + 云端后端 | 本机 `npm start`，服务仅监听 `127.0.0.1` |
| 账号 | 匿名玩家 + 登录方案 | 取消，固定单玩家 |
| 备份恢复 | 数据库备份演练 | 存档导出/导入 + 自动滚动备份 |
| AI 密钥 | 服务端环境变量 | 保留本地后端，密钥放 `.env`，不进前端与仓库 |

## 保留
数据库状态权威、AI 不写库、行动状态机与幂等、叙事与结算分离、Zod 校验 AI 输出、AI 故障降级、离线收益上限、NPC 记忆关联真实事件。

## 审计项处理
- 不适用（须写明理由）：E-04 所有权校验、F-06 权限边界、F-03 玩家请求限流（仅保留 AI 调用成本上限）。
- 简化：T-025 → 密钥保护 + 本机绑定检查；T-027 → 存档导出/导入测试；T-028 → 一键启动 + 回归。

## 设计决策（T-003 UI 评审结论，优先于原文）
- **界面**：按手绘草图。左侧图标栏（设置/任务/消息），主卡含名号、货币、境界、六维、气血/体力/内力、位置、日志，底部药丸导航（背包/功法/地图/行动）。
- **身份**：单机去掉 ID；名字下只显示头衔，点击名字展开称号与命格。
- **名号**：头衔、称号、命格都有评级与效果；**命格可变**；外貌评价归入称号，并推导隐藏属性魅力（魅力只在服务端，不进入契约，换算规则 S2 定）。
- **评级**：功法、头衔、称号、命格统一为 凡/黄/玄/地/天（`fan/huang/xuan/di/tian`）。效果类别：属性加成、经验系数、好感修正、概率修正，由数据表定义、程序结算。
- **六维**：神、力、敏、根、悟、福。
- **货币**：元宝、银两、铜钱，建议兑换 1 元宝 = 100 银两，1 银两 = 1000 铜钱（S2 落地）。
- **境界**：炼体 → 通窍 → 后天 → 先天 → 宗师 → 明神 → 陆地神仙。仅后天及以上拥有内力；无「修为」条，界面以境界下细进度线表示晋级经验，经验量由功法评级决定。

# 单机自用调整说明（相对 V1.0 文档基线）

项目确定为**完全单机、自己游玩、无公开上线计划**。以下调整优先于 V1.0 文档中的对应描述。

| 项目 | V1.0 | 调整后 |
|---|---|---|
| 数据库 | PostgreSQL | SQLite 本地文件（Drizzle） |
| 部署 | 静态托管 + 云端后端 | 本机 `npm start`，服务仅监听 `127.0.0.1` |
| 账号 | 匿名玩家 + 登录方案 | 取消，固定单玩家 |
| 备份恢复 | 数据库备份演练 | 存档导出/导入 + 自动滚动备份 |
| AI 密钥 | 服务端环境变量 | 保留本地后端，密钥放 `.env`，不进前端与仓库 |

## 保留
数据库状态权威、AI 不写库、行动状态机与幂等、叙事与结算分离、Zod 校验 AI 输出、AI 故障降级、离线收益上限、NPC 记忆关联真实事件。

## 审计项处理
- 不适用（须写明理由）：E-04 所有权校验、F-06 权限边界、F-03 玩家请求限流（仅保留 AI 调用成本上限）。
- 简化：T-025 → 密钥保护 + 本机绑定检查；T-027 → 存档导出/导入测试；T-028 → 一键启动 + 回归。

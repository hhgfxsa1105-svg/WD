# AI 配置指南

自由行动由 AI 把玩家的话转成结构化意图（见 `docs/ai-contract.md`）。没有 AI 时，固定选项、放置修炼、存档等全部功能照常使用。

## 三种模式（在 `.env` 里设置 `AI_PROVIDER`）
| 值 | 说明 |
|---|---|
| 留空 | 关闭 AI（默认） |
| `mock` | 本地**关键词模拟**，无需密钥，可先体验自由输入的流程；只认「修炼」「休息」「突破」「挂机」等关键词 |
| `openai-compatible` | 接入真实模型：任意兼容 `/v1/chat/completions` 的服务（国产模型厂商或中转站） |

## 接入真实模型
在 `.env` 里填四项（`.env` 已被 `.gitignore` 忽略，**密钥只放这里**）：
```
AI_PROVIDER=openai-compatible
AI_BASE_URL=https://你的服务商或中转站地址/v1
AI_API_KEY=你的密钥
AI_MODEL=服务商提供的模型名
```
- `AI_BASE_URL` 写到 `/v1` 为止即可（程序会补上 `/chat/completions`；已经写成完整地址也行）。
- 模型名以你的服务商为准。游戏对模型质量要求不高，便宜、快的小模型通常就够；越快越好，因为每次自由行动都要等它一次。
- 配置缺项或格式不对时，AI 自动关闭，启动日志会写明原因（不含密钥与地址），也可访问 `GET /api/v1/ai/status` 查看。

## 可选项（括号内为默认值）
| 变量 | 说明 |
|---|---|
| `AI_TIMEOUT_MS`（20000） | 单次请求超时 |
| `AI_MAX_RETRIES`（2） | 超时、网络错误、限流（429）、服务端错误（5xx）的最大重试次数；指数退避，并尊重 `Retry-After` |
| `AI_BACKOFF_MS`（500） | 重试退避起点 |
| `AI_JSON_MODE`（auto） | `auto`：优先请求 JSON 模式，供应商拒绝时自动降级并记住；`on` 强制；`off` 关闭 |
| `AI_MAX_OUTPUT_TOKENS`（1000） | 单次输出 token 上限（始终不会被调用方超过） |
| `AI_MAX_INPUT_CHARS`（6000） | 单次请求内容字符数上限；超过则**不发出**，也不占用额度 |
| `AI_DAILY_CALL_LIMIT`（200） | 每日调用次数上限，按本机日期统计，**重启后不清零**；设为 0 等于禁止调用 |

## 安全与费用
- 密钥只存在于本机后端的环境变量，不会进入前端、日志、接口响应或错误信息（含供应商回显密钥的情况，已脱敏并限长）。
- 调用记录（`ai_call_logs`）只存元数据：用途、模型、耗时、token 用量、状态、请求/回复长度；**不存提示词与回复全文**。
- 失败的调用同样计入每日额度（请求已发出，可能已计费）；进程崩溃时未结束的调用按保守口径计入。
- 额度的检查与预占在同一个同步步骤内完成，并发调用不会超出上限。

## 故障时会怎样
AI 超时、被限流、拒答、返回乱码，或额度用完，都不会影响基础功能；自由行动会得到「请使用固定选项」之类的降级提示（降级流程在 T-015、T-016 完成）。

## 内容
| 项 | 现状 |
|---|---|
| 魅力（隐藏属性）换算 | 每 10 分外貌分 1 点；只登记了一个称号，其余按 50 分 |
| 头衔 / 称号 / 命格 | 只有示例各一个；命格「可变」的触发规则未定义；效果仅 `exp_multiplier` 被规则消费，其余类别只做展示 |
| 评级 | 统一凡/黄/玄/地/天五档；是否要为命格等使用不同档位待定 |
| 丹药获取 | 仅初始赠送 1 枚凡阶；商店/任务/掉落未定 |
| 功法 | 无功法系统；功法获取、切换、评级与经验关系未定 |
| 境界突破后的成长 | 只有数值成长，无境界专属能力 |
| 地点 / NPC / 势力 / 任务 | S4–S5 内容，尚无设定 |
| 初始角色 | 林惊鸿、六维各 5、头衔山门弟子、称号初出茅庐、命格七杀，均为示例 |

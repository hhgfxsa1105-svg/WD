# 江湖志 · AI 驱动的文字放置武侠游戏

*«一念入江湖，一行定命运。
以规则构建真实的武侠世界，以 AI 演绎不可预设的江湖人生。»*

## *项目简介*

江湖志是一款基于 Web 的 AI 驱动文字放置武侠游戏。

游戏融合传统放置养成、开放式文字冒险与大语言模型。玩家可以修炼武学、提升境界、探索江湖、结交人物、加入门派，也可以通过自然语言自由描述行动。

不同于传统的固定分支剧情，江湖志希望让玩家的每一次选择都能对人物关系、任务进程和世界状态产生真实影响。

项目采用 程序规则引擎 + AI 剧情引擎 的混合架构：程序负责游戏规则与状态一致性，AI 负责理解玩家意图、演绎人物反应和生成动态剧情。

## *核心设计理念*

- 持续世界：世界时间、修炼进度、NPC 状态和事件能够持续推进。
- 自由行动：支持预设选项与自然语言输入，不局限于固定剧情分支。
- 可信判定：行动结果由角色属性、环境、前置条件和规则共同决定。
- 动态人物：NPC 拥有独立身份、目标、人物关系和历史记忆。
- 长期成长：通过修炼、武学、境界、装备和江湖经历逐步成长。
- 状态可追溯：关键行动、资源变化和事件结果能够记录、验证与审计。

## *系统设计*

项目采用模块化单体架构，优先保证核心玩法可运行、数据可靠和开发过程可维护。

## *主要模块：*

1. 角色与养成：属性、境界、武学、装备、背包和资源。
2. 放置与时间：修炼进度、离线收益、世界时钟和事件调度。
3. 行动判定：行动解析、条件校验、概率计算和结果结算。
4. AI 剧情：意图理解、NPC 对话、事件生成和叙事反馈。
5. 人物与关系：NPC 状态、人物关系、历史记忆和任务承诺。
6. 江湖世界：地图、地点、门派、势力关系和动态事件。
7. 持久化与审计：存档、行动历史、状态变更记录和成本统计。

## *AI 与规则引擎的职责*

AI 可以提出行动方案、分析风险并生成剧情，但不能直接决定最终游戏数值或绕过规则。

所有重要行动都必须经过服务端校验，合法的状态变更由游戏规则引擎执行并持久化。

## *开发原则*

- 优先实现完整、可玩的核心循环，再扩展世界规模。
- 核心游戏规则必须可测试、可验证。
- AI 输出必须经过结构校验和业务规则校验。
- 普通挂机与数值结算不依赖持续调用 AI。
- 敏感密钥仅保存在服务端，不提交到代码仓库。
- 重要状态变更必须可追溯，关键操作必须具备重复请求保护。
- 每个阶段完成后，依据检查清单进行验收。

## *当前状态*

项目处于立项与技术设计阶段，正在建立项目文档、技术规范和开发任务体系。

当前首要目标是完成首个可玩的网页原型，跑通：

修炼成长 → 遭遇事件 → 玩家行动 → 规则判定 → 世界状态变化 → 剧情反馈 → 存档。

## *项目愿景*

江湖不应只是预先写好的剧情树。

玩家的选择应当留下痕迹，人物应当记得恩怨，世界应当产生变化，而每一次新的行动都可能开启一段未曾预设的江湖故事。

让规则守住真实，让 AI 赋予江湖变化。
